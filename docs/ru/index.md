# Takt — документация проекта

[English](../en/index.md)

Takt («Такт») — Telegram Mini App для личного учёта времени сотрудников МГРИ. Приложение помогает видеть общее время присутствия, выбранное окончание рабочего дня и время сверх него.

## Основной сценарий

Сотрудник сохраняет время окончания дня и отмечает приход и уход. Если отметка внесена позднее, указывается фактическое время. Общее время включает перерывы; их можно отмечать отдельно для себя. Правила расчёта, пропущенные отметки и первый запуск описаны в [сценариях учёта](product/time-accounting.md).

Личный учёт не заменяет официальный табель и не доказывает физическое присутствие. Сотрудник видит свои записи; администратор управляет доступом и просматривает индивидуальный учёт.

## Устройство проекта

Для клиента выбраны React, TypeScript и Vite, для сервера — Python и FastAPI, для хранения данных — PostgreSQL. Клиент и сервер взаимодействуют через REST API по HTTP с JSON; контракт описывается в OpenAPI.
