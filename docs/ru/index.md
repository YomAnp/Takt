# Takt — документация проекта

[English](../en/index.md)

Takt («Такт») — Telegram Mini App для личного учёта времени сотрудников колледжа. Основная задача проекта — помочь сотруднику понимать, сколько времени учтено, сколько осталось до нормы и когда она будет выполнена.

## Основной сценарий

Сотрудник задаёт требуемое время присутствия и вносит время прихода. По отметкам и применимым правилам рассчитываются учтённое время, остаток и время выполнения нормы. Сценарий включает завершение дня, исправление отметок, просмотр истории и статистики по своим записям.

Личный учёт времени не приравнивается к официальному табелю или подтверждению фактического присутствия. Доступ к записям коллег и полномочия администрации требуют отдельного определения.

## Устройство проекта

Для клиента выбраны React, TypeScript и Vite, для сервера — Python и FastAPI, для хранения данных — PostgreSQL. Клиент и сервер взаимодействуют через REST API по HTTP с JSON; контракт описывается в OpenAPI.
