# Установка на сервер

[На главную](../index.md) · [English](../../en/development/hosting.md)

`scripts/host.py` собирает и запускает Takt из обычного клона репозитория. Домен, бот и владелец задаются при установке. На сервере нужны Python 3.10 или новее, Docker Engine и плагин Compose. Инструкции Docker доступны для [Ubuntu](https://docs.docker.com/engine/install/ubuntu/) и [Debian](https://docs.docker.com/engine/install/debian/).

## Подготовка

Создайте бота через [BotFather](https://t.me/BotFather) и получите его токен. Домен должен указывать на сервер; порты 80 и 443 должны быть доступны. Caddy получает и обновляет сертификат HTTPS при этих условиях, согласно [документации](https://caddyserver.com/docs/automatic-https).

Из корня клона:

```sh
python3 scripts/host.py setup
```

Установщик запросит домен, скрытый токен и `@username` владельца. Он проверит бота, сохранит параметры в `.env.host`, создаст случайный пароль PostgreSQL, соберёт клиент и сервер, применит миграции и запустит контейнеры. После проверки доступности приложения настроит имя, аватарку, описание бота, команды и кнопку Mini App.

Настройки и токен не передаются в сборку клиента. Файл `.env.host` исключён из Git и на Linux доступен только владельцу файла. При повторной настройке сохраняется пароль существующей БД.

## Владелец и администраторы

После установки владелец открывает Mini App из своего Telegram-аккаунта. Сервер сверяет подписанный `username` с настройкой и однократно закрепляет его Telegram ID. Смена ника не передаёт права другому человеку. Изменение ника в конфиге также не переносит уже закреплённое владение.

| Роль | Возможности |
| --- | --- |
| Участник | Свои отметки, настройки и статистика |
| Администратор | Список пользователей, индивидуальный учёт и управление доступом участников |
| Владелец | Те же действия, назначение и снятие администраторов, управление их доступом |

Управление находится в настройках приложения, раздел «Пользователи». Нельзя заблокировать себя или владельца. Блокировка отзывает сессии; восстановление доступа требует нового входа.

## Telegram

Установщик задаёт имя «Такт», полное и краткое описание, аватарку, команды и кнопку запуска. Оформление применяется при установке и обновлении. Кнопка в чате открывает HTTPS-адрес приложения. Отдельный основной ярлык Mini App в профиле настраивается через BotFather; [настройки Mini Apps](https://core.telegram.org/bots/webapps).

Исходник логотипа — `apps/frontend/public/brand/logo.svg`, аватарка — `apps/frontend/public/brand/avatar.jpg`. Повторный запуск сохраняет текущую аватарку, если файл не менялся. Если её заменили или удалили в Telegram, установщик восстановит изображение из проекта.

Бот отвечает на `/start` и `/help` в личном чате. Используется один процесс long polling. Существующий webhook установщик не удаляет: для Takt нужен отдельный бот либо явно освобождённое подключение.

## Обновление и обслуживание

Для уже установленного Takt выполните в папке проекта:

```sh
git pull --ff-only
python3 scripts/host.py up
```

Настройки из `.env.host`, пароль БД, пользователи и отметки сохраняются. Образы собираются до остановки приложения. Затем API и бот приостанавливаются, создаётся резервная копия БД, применяются миграции и запускается новая версия. Обновление не требует повторного ввода домена, токена или владельца.

После первого обновления доступна одна команда, которая получает новую версию из `origin/main` и запускает её установщик:

```sh
python3 scripts/host.py update
```

Команда работает в ветке `main` и принимает только перемотку вперёд. Локальные изменения исходников и собственные коммиты сохраняются; при их наличии исходники нужно обновить самостоятельно. Для установки из архива используйте новые исходники и команду `up`.

Локальная правка `apps/frontend/Caddyfile` поддерживается как overlay хоста: на время перемотки она убирается, затем возвращается до сборки контейнеров. Если новая версия изменила тот же участок, обновление остановится и попросит разрешить конфликт.

Имя Docker-проекта хранится в `TAKT_PROJECT_NAME`. Если старая установка запускалась с `--project`, при первом обновлении передайте то же имя; последующие команды используют сохранённое значение. Параллельные команды установки для одного конфига блокируются.

```sh
python3 scripts/host.py status
python3 scripts/host.py logs
python3 scripts/host.py backup
python3 scripts/host.py stop
```

Резервные копии создаются в `backups/` в формате `pg_dump -Fc`; незавершённый файл не становится готовой копией. Каталог исключён из Git. Храните копии и вне сервера.

Если создание копии завершилось ошибкой, предыдущие контейнеры возобновляют работу. При ошибке миграции API и бот остаются остановленными; путь к копии выводится в терминал. После устранения причины повторите `up`. Данные и сертификаты остаются в существующих томах.

Параметры `--config` и `--project` позволяют выбрать отдельный файл настроек и имя новой установки. Для проверки контейнеров через HTTP используется отдельная конфигурация:

```sh
python3 scripts/host.py setup --local --config .env.host.local --project takt-local --port 8080
```

Этот режим проверяет сборку, запуск и доступность; подключение к Telegram использует основной HTTPS-режим. Для применения оформления бота без пересборки контейнеров:

```sh
python3 scripts/host.py configure-bot
```
