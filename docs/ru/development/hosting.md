# Установка на сервер

[На главную](../index.md) · [English](../../en/development/hosting.md)

`scripts/host.py` собирает и запускает Takt из обычного клона репозитория. Домен, бот и владелец задаются при установке. На сервере нужны Python 3.10 или новее, Docker Engine и плагин Compose. Инструкции Docker доступны для [Ubuntu](https://docs.docker.com/engine/install/ubuntu/) и [Debian](https://docs.docker.com/engine/install/debian/).

## Подготовка

Создайте бота через [BotFather](https://t.me/BotFather) и получите его токен. Домен должен указывать на сервер; порты 80 и 443 должны быть доступны. Caddy получает и обновляет сертификат HTTPS при этих условиях, согласно [документации](https://caddyserver.com/docs/automatic-https).

Из корня клона:

```sh
python3 scripts/host.py setup
```

Установщик запросит домен, скрытый токен и `@username` владельца. Он проверит бота, сохранит параметры в `.env.host`, создаст случайный пароль PostgreSQL, соберёт клиент и сервер, применит миграции и запустит контейнеры. После проверки доступности приложения настроит описание бота, команды и кнопку Mini App.

Настройки и токен не передаются в сборку клиента. Файл `.env.host` исключён из Git и на Linux доступен только владельцу файла. При повторной настройке сохраняется пароль существующей БД.

## Владелец и администраторы

После установки владелец открывает Mini App из своего Telegram-аккаунта. Сервер сверяет подписанный `username` с настройкой и однократно закрепляет его Telegram ID. Смена ника не передаёт права другому человеку. Изменение ника в конфиге также не переносит уже закреплённое владение.

| Роль | Возможности |
| --- | --- |
| Участник | Свои отметки, настройки и статистика |
| Администратор | Список пользователей, индивидуальный учёт и управление доступом участников |
| Владелец | Те же действия, назначение и снятие администраторов, управление их доступом |

Управление находится в настройках приложения, раздел «Пользователи». Нельзя заблокировать себя или владельца. Блокировка отзывает сессии; восстановление доступа требует нового входа.

## Telegram

Установщик использует поддерживаемые методы Bot API: `setMyCommands`, `setMyDescription`, `setMyShortDescription` и `setChatMenuButton`. Кнопка в чате открывает HTTPS-адрес приложения. Отдельный основной ярлык Mini App в профиле настраивается через BotFather; [настройки Mini Apps](https://core.telegram.org/bots/webapps).

Бот отвечает на `/start` и `/help` в личном чате. Используется один процесс long polling. Существующий webhook установщик не удаляет: для Takt нужен отдельный бот либо явно освобождённое подключение.

## Обновление и обслуживание

После получения новой версии исходников:

```sh
python3 scripts/host.py up
python3 scripts/host.py status
python3 scripts/host.py logs
python3 scripts/host.py backup
python3 scripts/host.py stop
```

Обновление повторно собирает приложение и применяет миграции, сохраняя данные PostgreSQL и сертификаты. Резервная копия создаётся в `backups/` в формате `pg_dump -Fc`; этот каталог исключён из Git. Копии нужно хранить и вне сервера.

Параметры `--config` и `--project` позволяют выбрать отдельный файл настроек и имя установки. Для проверки контейнеров через HTTP используется отдельная конфигурация:

```sh
python3 scripts/host.py setup --local --config .env.host.local --project takt-local --port 8080
```

Этот режим проверяет сборку, запуск и доступность; подключение к Telegram использует основной HTTPS-режим. Для повторной регистрации меню бота есть команда `configure-bot`.
